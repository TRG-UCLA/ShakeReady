Fragility sets

A fragility set gives, for each class of structure, the ground motion at which damage becomes likely. Sets are published as data files so the curves and the assumptions behind them can be inspected.

SetApplies toDescriptionDownload
HAZUS highway bridgesNBI bridges The 28 highway bridge classes of FEMA's Hazus Earthquake Model (Technical Manual, Hazus 6.1, Section 7.1): median spectral acceleration at 1.0 second for slight, moderate, extensive and complete damage, lognormal with a dispersion of 0.6, with the manual's adjustments for skew and number of spans. Every bridge is assigned a class from its NBI fields. These are generic curves for screening an inventory. They do not reflect seismic retrofits, which the NBI does not record, and 3,571 of the records are culverts, for which bridge curves are a rough fit at best. JSON

Sources and currency

Bridge records come from the FHWA National Bridge Inventory. This site uses the 2025 California file, the final year published in the long-standing Coding Guide format; later submissions follow the newer Specifications for the National Bridge Inventory. The script that converts the FHWA file into the map layer is in this site's repository, so the layer can be rebuilt from the source. Building instrumentation details come from the Center for Engineering Strong Motion Data. Please cite the original sources alongside this site when using the data.
