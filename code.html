Code

The software behind the data pipeline and the map.

This website

HTML · JavaScript · Leaflet

The site itself is open: a static, dependency-light application served from its own repository. The map renders 25,000+ structures with marker clustering and client-side filtering, with no server or API keys involved.

Bridge inventory builder

Python · standard library only

Converts a state file from the FHWA National Bridge Inventory into the map's bridge layer and a labeled CSV: decodes packed coordinates, material and design codes, county codes and condition ratings. tools/build_bridges.py

HAZUS bridge fragilities

Python · standard library only

Assigns each National Bridge Inventory record its HAZUS highway bridge class and evaluates the fragility curves: class medians, the skew, span and spectral-shape adjustments, and damage-state probabilities. It checks itself against the worked example in FEMA's manual. tools/hazus_bridges.py

SR-HazardMaker

Made by E. Taciroglu · free to use, BSD 3-Clause license · JavaScript in the browser · Python on the command line

Converts USGS hazard-model files, USGS ShakeMaps and plain tables of points into ShakeReady hazard layers, checks them, and previews the result. The browser and command-line versions are tested to produce the same layers. Use it here · standalone page · repository and guide

Bridge damage, reference calculation

Python · standard library only

An independent implementation of the bridge damage table the map offers for download, used to check the map and to let anyone reproduce a table. tools/damage_reference.py
