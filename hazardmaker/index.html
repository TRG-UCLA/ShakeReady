Keeping it in this browser lets you use the layer on the ShakeReady map straight away, on this computer only. It is marked as yours and unpublished, and any damage table you download says so.

To publish it for everyone, send the two downloaded files to the ShakeReady maintainers, or open a pull request that adds them to the hazard repository. A layer is reviewed before it is listed.
