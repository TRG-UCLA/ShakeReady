Methods and provenance

Where each dataset comes from, what was done to it, the choices that were made along the way, and what was checked. Anyone using results from this site should be able to trace them back to their source.

How to trace a result

Every published file is listed below with a checksum. If the checksum of a file you hold matches, it is the file described here. The same record is available in machine-readable form as data/provenance.json, and the complete history of every change is in the project repository. Each choice has an identifier, such as HZ-07, that can be quoted alongside a result.

Datasets and their sources

HAZUS fragilities for bridges

Each bridge in the National Bridge Inventory is assigned one of the 28 highway bridge classes of FEMA's Hazus Earthquake Model, using the classification scheme in Table 7-1 of the technical manual. A class gives four median values of spectral acceleration at a period of 1.0 second, one each for slight, moderate, extensive and complete damage (Table 7-6). Each fragility curve is lognormal with a dispersion of 0.6.

The medians are then adjusted for the individual bridge, following the manual:

  • Skew: Kskew = √sin(90° − α), where α is the skew angle (Equation 7-1).
  • Number of spans: K3D = 1 + A / (N − B), with A and B from Table 7-2.
  • Spectral shape: Kshape = 2.5 × Sa(1.0 s) / Sa(0.3 s) (Equation 7-2), used only for classes flagged in Table 7-1.
  • The slight median is multiplied by the smaller of 1 and Kshape where that factor applies. The moderate, extensive and complete medians are multiplied by Kskew × K3D.

The values shown in a bridge's popup on the dashboard are these adjusted medians. The full set is published as hazus_highway_bridges.json, and the code is tools/hazus_bridges.py.

Choices made in applying HAZUS

The manual is silent or inconsistent on several points. Each choice made is recorded here with its basis and the number of bridges it affects, so that it can be reviewed and, if need be, changed.

Hazard layers

A hazard layer is a grid of ground motions that the dashboard can display and use to estimate damage. There are two kinds. A probabilistic layer is a hazard map: it gives, for each place, the shaking with a set chance of being exceeded there, at one or more probability levels. It does not describe one earthquake. A scenario layer holds the ground motions of a single earthquake, computed or recorded.

Every layer states its source and the ground condition its values assume. Layers are kept in the project's hazard repository, which also describes the file format and how to submit a layer.

Making a layer

Layers are made with SR-HazardMaker, a tool made by E. Taciroglu, which converts ground-motion files into the format the dashboard reads. It accepts USGS hazard-model files, USGS ShakeMaps, and plain tables of points on a regular grid, and it will not build a layer that does not state its source. SR-HazardMaker is a tool in its own right, with its own repository, a command-line version, and its own tests. It is free to use under the BSD 3-Clause license, and is citable as doi:10.5281/zenodo.24356049. This site uses a released version of it unchanged: .

Computed scenarios

SR-HazardMaker can also compute the shaking of an earthquake that someone describes: a magnitude, a style of faulting, a fault, and a ground condition. Such a layer is a calculation with a ground-motion model, not a recording, and it says so. Its inputs are written into it, so it can be recomputed.

Damage estimates

When a hazard layer is selected on the dashboard, damage is estimated for each bridge in four steps:

  1. Read the spectral accelerations at 1.0 second and 0.3 second at the bridge from the hazard layer.
  2. Adjust the bridge's class medians for skew, number of spans and spectral shape, as described under HAZUS fragilities for bridges.
  3. For each damage state, compute the probability of reaching or exceeding it: Φ( ln( Sa(1.0 s) / median ) / 0.6 ), where Φ is the standard normal distribution function.
  4. Take differences to get the probability of each of the five states: none, slight, moderate, extensive and complete.

The dashboard colors each bridge by the result and offers the full table for download, one row per bridge, with its sources written at the top of the file. Anyone can reproduce a table with tools/damage_reference.py, a separate implementation of the same calculation.
