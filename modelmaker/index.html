SR-ModelMaker

OpenSeesPy models of structures for ShakeReady's Local analysis. Made by E. Taciroglu. In development.

What it makes now

The shear building. Rigid floors that move sideways without rotating, a lumped mass at each floor, and one bilinear spring per story. One story is a single-degree-of-freedom oscillator. You give the number of stories, the story height, the floor mass, the first period and the yield strength as a fraction of the weight; the stiffnesses and strengths follow. Second-order effects are an option. It is not a frame analysis.

The result is an ordinary OpenSeesPy file that you can read and edit.

Make a shear building in Local analysis

Bringing your own model

Local analysis also takes a model file of your own, if it defines build() and returns a description of the model: the direction of shaking, the base nodes, one node per floor, the story heights, the periods, gravity in the model's units, and the units. Only OpenSeesPy models are supported.

Coming next

Reading any OpenSeesPy model in the browser, showing the structure, and editing it. More templates, a bridge among them.

How it is checked

What OpenSees gives for a shear building is compared with solutions worked out separately, by other methods: elastic buildings of one and three stories, and a yielding story. The file made in the browser is required to be the same as the one the Python tool makes.
