Local analysis

One structure: bring ground motions, bring a model, run the analysis on your own computer with OpenSees, and read the response here. Your files are read on your own computer. Nothing is uploaded.

1Ground motions

A suite, or a single motion. Add record files in PEER's AT2 format, with acceleration in g. To work out what a site calls for, see SR-SuiteMaker.

2Model

An OpenSeesPy model, from SR-ModelMaker or your own.

Rigid floors that move sideways without rotating, a mass at each floor, and one bilinear spring per story. One story is a single-degree-of-freedom oscillator. It is not a frame analysis.

See the model file this makes

    

    

      
A Python file that defines build(). It must build the model in OpenSeesPy and return a description of it: the direction of shaking, the base nodes, one node per floor, the story heights, the periods, gravity in the model's units, and the units. The shear building's model file shows the form.

      

    


  
3Run it on your computer

    
The motions and the model are packed into one folder with a run script. It needs Python and OpenSeesPy, and nothing else.

    

    

    

    
Unzip it. Then, in that folder:
pip install openseespy
python run.py
It writes results.json in the same folder. Bring that file to step 4.
